"Maximum" reads a finer elevation dataset that we hold only for part of Europe (roughly France and its neighbours) - it is curated by hand and cannot be downloaded on demand. Outside that area there is no 1 arcsec data at all, so choose what should happen when some of your selected area is not covered. "Standard" and "High" use the global 3 arcsec dataset and are available everywhere.


Either way, the generated map contains a dem_provenance.txt listing exactly which elevation data each part of it was built from.


Note: the basemap's hillshade layer is only as large as our elevation data coverage allows - if your selected bounds reach outside that coverage, the hillshade is cropped to whatever is available (or omitted entirely if there is none), while the rest of the map is built normally. The crop is recorded in dem_provenance.txt inside the map, so you can tell what you got.
